# 산학프로젝트 10조 (2025.11.3 ~ 2025.11.24)
## Emotion Garden: 감정 피드백 기반 정서 관리 기능성 게임

### 프로젝트 소개
Emotion Garden은 표정 인식 기반 감정 분석을 통해 사용자의 정서를 게임 요소와 보상 시스템으로 피드백하여, 지속적인 심리 관리와 긍정적 정서 형성을 돕는 기능성 감정 게임입니다.

### 핵심기능
- 표정 인식 미니게임: 카메라 입력으로 감정을 판별하고 점수/보상을 제공
- 꾸미기·수집 시스템: 포인트로 아이템을 수집하고 캐릭터 및 정원 꾸미기
- 감정 기록/로그: 자가진단 리스트를 통해 감정을 기록·통계화하여 정서 상태 확인
